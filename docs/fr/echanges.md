**À quoi ça sert :** donner, vendre ou troquer des objets et de l'argent entre personnages, en jeu, sans passer par le MJ.

**Exemple :** clic droit sur une dague de l'inventaire → **Échanger l'objet** → le personnage d'en face. Il accepte ; une fenêtre s'ouvre chez les deux, chacun ajoute ce qu'il veut, chacun valide, c'est fait.

## Les réglages

Les **paramètres du système** : **Activer le système d'échange** (coché par défaut), puis **Échanges** → **Configurer les échanges** :

- **Familles échangeables** : les modèles d'atelier dont les objets s'échangent (« Arme », « Potion »).
- **Exceptions** : des objets précis qui ne s'échangent jamais, glissés dans la zone prévue.
- **Argent** : les monnaies déclarées dans [Les marchands](#marchands). Sans monnaie, pas d'argent dans les échanges.
- **Distance maximale** entre les pions (0 = aucune).
- **Sons** : demande, terminé, annulé, pour les deux participants.

## Le déroulé

1. **Échanger l'objet** n'apparaît que sur un objet échangeable.
2. Le destinataire est un personnage joueur dont le joueur est connecté, et à portée. Le MJ peut lancer un échange depuis un PNJ.
3. Le destinataire **accepte** ou **refuse**.
4. Une fenêtre à deux colonnes : **Vous donnez** (glissez des objets de votre fiche, la quantité d'une pile, de l'argent) et **Vous recevez**.
5. Quand l'un change son offre, l'autre doit revalider. Les deux ont validé : l'échange est fait. Fermer la fenêtre l'annule.
6. Une carte « Échange » est chuchotée au MJ et aux deux joueurs.

## Les règles

- Un objet qui en contient d'autres (un sac plein) doit être vidé avant.
- Les objets reçus vont dans le premier conteneur qui les accepte. Dans une grille spatiale sans place, l'objet attend **hors de la grille** et la fenêtre « Objets sans place » s'ouvre : le ranger, le poser au sol, le jeter ou le rendre.
- Un objet verrouillé par un effet ne s'échange pas.
