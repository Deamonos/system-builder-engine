**À quoi ça sert :** l'immersion. Un personnage que les joueurs n'ont pas encore rencontré s'appelle « Inconnu » chez eux, jusqu'à ce qu'il se présente.

**Exemple :** les joueurs croisent une marchande. Ils voient « Inconnu » sur son pion, dans le combat et dans le chat. Elle se présente : le MJ clique sur l'œil de sa fiche, et son nom apparaît partout, y compris dans les anciens messages.

## Comment ça marche

- **Qui est masqué** : tout personnage sans joueur propriétaire. Un personnage de joueur n'est jamais masqué, et le MJ voit toujours le vrai nom.
- **Le bouton œil** dans l'en-tête de la fiche (MJ) : silhouette = masqué, œil = révélé.
- **Pion non lié** : chaque pion se révèle à part (révéler un garde ne révèle pas les autres gardes). **Pion lié** : toute la fiche.

## Les réglages

Les **paramètres du système** : **Masquer l'identité des PNJ** (activer ou couper) et **Nom affiché pour un inconnu** (vide = « Inconnu » ; par exemple « ??? »).

## Ce qui est couvert

L'étiquette du pion, le suivi de combat et le [carrousel](#initiative), le titre des fiches, le répertoire, le chat (l'orateur, les cartes du système, les messages d'autres modules) et les info-bulles.

## Pour aller plus loin

C'est de l'immersion, pas un secret : le vrai nom arrive sur l'ordinateur du joueur, qui peut le trouver dans la console du navigateur. Pour des objets mystérieux : [Les objets non identifiés](#identification).
