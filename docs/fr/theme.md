**À quoi ça sert :** donner à tout le système l'allure de votre univers. Les couleurs, les polices, le fond des fenêtres, les sons d'interface, les info-bulles et les messages du chat se règlent en un seul endroit.

**Exemple :** un jeu d'horreur. Un thème « Asile » sombre : fond gris-vert, accent rouge sang, police à machine à écrire, texture de papier taché, un grincement à l'ouverture des fenêtres.

## Ouvrir le thème

Les **paramètres du système** → **Configurer le thème**.

En haut, **Thème réglé** : le thème que vous modifiez. **Sombre** et **Clair** sont les thèmes de base, toujours là ; vos thèmes viennent ensuite. Un **aperçu** (une fiche, la barre latérale, un menu) suit chaque réglage.

![La fenêtre du thème : le thème réglé, ses trois parties, l'aperçu et les onglets de la partie Général](img/theme.webp)

| Bouton | Ce qu'il fait |
|---|---|
| **Nouveau thème** | Une copie du thème Clair de base, à votre nom. |
| **Dupliquer**, **Renommer**, **Supprimer** | Sur le thème réglé. |
| **Proposé aux joueurs** | Les joueurs peuvent le choisir. |
| **Imposé à tous** | Toute la table le voit, sans choix. |
| **Fenêtres de Foundry** | Pour un thème créé : les fenêtres de Foundry passent en **Claires** ou **Sombres** quand il est choisi. |

Chaque joueur choisit son thème dans les paramètres du système : **Thème de l'interface**. **Automatique** suit le clair ou le sombre de Foundry.

> Sombre et Clair partagent les polices, l'habillage, les médias et le CSS ; chacun a sa palette. Un thème créé a une seule palette.

## Les onglets

Trois parties : **Général**, **Info-bulles** et **Messages du chat**. La partie Général a ses propres onglets.

| Onglet | Ce qu'on y règle |
|---|---|
| **Couleurs** | Les surfaces (champs, fond, panneaux, bordures), six nuances, les textes, l'accent, les liens, la barre de défilement, et les états : **Positif** (bonus, réussite), **Négatif** (malus, échec), **Alerte**. Plus, en option, les couleurs de l'**Interface de Foundry** (barre latérale, boutons d'icônes). |
| **Polices** | La police principale et celle des titres, leur style (gras, italique, majuscules, petites majuscules), l'espacement des titres, la taille de base. Les polices proposées sont celles installées dans Foundry, y compris les vôtres. |
| **Interface et habillage** | La barre de titre des fenêtres (visible ou cadre masqué), leur opacité (pour voir la scène derrière), une **texture de fond**, une **image d'en-tête** avec fondu. Chemin d'image ou code SVG collé. Plus du **HTML libre** pour décorer les fenêtres ou poser un calque sur l'interface. |
| **Médias** | Les sons d'interface : ouverture et fermeture d'une fenêtre, changement d'onglet. Seul celui qui clique les entend. |
| **CSS avancé** | Des règles CSS ajoutées après le thème, pour aller plus loin. |
| **Info-bulles** | Fond, texte, bordure, arrondi, ombre, police, largeur, image ou SVG de fond. Couleur vide = celle du thème. |
| **Messages du chat** | Le cadre des messages, le look commun des cartes, les bandeaux de résultat (texte, couleur, icône, son), les jets (modificateurs, avantage), le bouton « Lancer mon jet », puis des retouches par type de carte. |

**Aperçu à l'écran** essaie le thème sur tout Foundry, sans l'enregistrer. **Enregistrer** le garde ; **Réinitialiser** revient aux réglages d'origine.

## Partager un thème

**Exporter** produit un fichier : tout le thème (général, info-bulles, chat), ou une seule partie. **Importer** le crée comme nouveau thème, ou remplace celui que vous réglez.

## Pour aller plus loin

Une fiche peut avoir son propre style, indépendant du thème : voir [Le thème d'un modèle](#theme-modele).
