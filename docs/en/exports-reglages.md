**What it's for:** knowing what can be shared, and where. Almost every SBE setting has its **Export** and **Import** buttons: build a system once, reuse it everywhere.

**Example:** to start a new campaign with your rules, export your templates, effects, combat rules and theme; import them into the new world.

## What exports

| What | Where |
|---|---|
| **A template** (structure) | The workshop: **Export structure**. See [Sharing a template](#import-export). |
| **The theme** (general, tooltips, chat) | System settings → **Configure Theme**: all of it, or one part. |
| **A template's theme** | Workshop, ⋮ menu → **Template theme**. |
| **Effects** | Effect manager: **Export effects (JSON)**. |
| **Combat rules** | System settings → **Combat rules**. |
| **Area templates** | System settings → **Draw the area templates**. |
| **Bodies** (hit locations) | System settings → **Bodies**. |
| **Token bars** | System settings → **Token bars**: all of them, or one. |
| **A template's HUD** | Workshop, ⋮ menu → **Template HUD**. |
| **Icon markers** | Their settings window, in the item template's options. |
| **Calendars** | System settings → **Set up the calendar**. |
| **Languages** | System settings → **Open languages**. |
| **Vision modes** | System settings → **Open vision modes**. |
| **The combat carousel's theme** | System settings → **Combat carousel**. |
| **A lookup table** | As CSV, in its settings window. |

## On import

- Everything first goes through a **check**: a file that isn't the right export is refused, with a clear message.
- Most imports **add** to what exists; some offer to **replace**. Nothing is overwritten without saying so.
- After an import, **check then save**: many windows show the import before keeping it.

## What doesn't export

- **Values** of sheets and items, nor the characters and world items themselves.
- **Files** (images, sounds): only their paths travel. Copy the files into the new world at the same place.

## Going further

Keep your exports in a folder of your own, named by date: a template exported before a big change is a way back with **Replace the whole structure**.
