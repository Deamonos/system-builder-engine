**What it's for:** giving the whole system the feel of your world. Colors, fonts, window backgrounds, interface sounds, tooltips and chat messages are all set in one place.

**Example:** a horror game. A dark "Asylum" theme: grey-green background, blood-red accent, a typewriter font, a stained paper texture, a creak when windows open.

## Opening the theme

The **system settings** → **Configure Theme**.

At the top, **Theme being edited**: the theme you are changing. **Dark** and **Light** are the base themes, always there; your themes come after them. A **preview** (a sheet, the sidebar, a menu) follows every setting.

![The theme window: the theme being edited, its three parts, the preview and the General part's tabs](img/en/theme.webp)

| Button | What it does |
|---|---|
| **New theme** | A copy of the base Light theme, with your name. |
| **Duplicate**, **Rename**, **Delete** | On the theme being edited. |
| **Offered to players** | Players can choose it. |
| **Imposed on everyone** | The whole table sees it, no choice. |
| **Foundry windows** | For a created theme: Foundry's windows switch to **Light** or **Dark** when it is chosen. |

Each player picks their theme in the system settings: **Interface theme**. **Automatic** follows Foundry's light or dark mode.

> Dark and Light share fonts, dressing, media and CSS; each has its own palette. A created theme has a single palette.

## Tabs

Three parts: **General**, **Tooltips** and **Chat messages**. The General part has its own tabs.

| Tab | What you set there |
|---|---|
| **Colors** | Surfaces (fields, background, panels, borders), six tones, texts, the accent, links, the scrollbar, and states: **Positive** (bonus, success), **Negative** (penalty, failure), **Warning**. Plus, optionally, the colors of the **Foundry interface** (sidebar, icon buttons). |
| **Fonts** | The main font and the headings font, their style (bold, italic, uppercase, small caps), heading letter spacing, base size. The fonts offered are those installed in Foundry, including yours. |
| **Interface and dressing** | The windows' title bar (visible or hidden frame), their opacity (to see the scene behind), a **background texture**, a **header image** with a fade. Image path or pasted SVG code. Plus **free HTML** to decorate windows or lay an overlay on the interface. |
| **Media** | Interface sounds: a window opens or closes, a tab changes. Only the one clicking hears them. |
| **Advanced CSS** | CSS rules added after the theme, to go further. |
| **Tooltips** | Background, text, border, corners, shadow, font, width, background image or SVG. Empty color = the theme's. |
| **Chat messages** | The message frame, the shared look of cards, the result banners (text, color, icon, sound), rolls (modifiers, advantage), the "Roll" button, then tweaks per card type. |

**On-screen preview** tries the theme on all of Foundry, without saving. **Save** keeps it; **Reset** goes back to the original settings.

## Sharing a theme

**Export** produces a file: the whole theme (general, tooltips, chat), or a single part. **Import** creates it as a new theme, or replaces the one you are editing.
