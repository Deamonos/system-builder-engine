**What it's for:** a text written in a language the character doesn't know is scrambled for their player. Whoever knows it reads it; the GM reads everything.

**Example:** an "Elvish" language, key `elvish`. On Elara's sheet, a number `elvish` at 100: she reads everything. Brann has 40: he reads 40% of the words, always the same ones. An inscription in the journal marked "Elvish" reads differently for each of them.

## Creating a language

**System settings** → **Character languages** → **+ Language**:

| Setting | What it does |
|---|---|
| **Name** and **color** | The passage is underlined in this color for the GM. |
| **Language key** | A component with the same key on the sheet grants the language: a **number** gives the mastery % (100 = everything, 0 = nothing), a ticked **checkbox** counts as 100%. Items and effects raise it (an equipped translator: `elvish` + 50). |
| **Scrambling** | Shuffled letters, **symbols** (an alphabet of your own: runes, ideograms) or a masked passage (█). A **font** for the scrambled words. A preview shows a sentence at 0, 50 and 100%. |
| **Name visible to players** | Unchecked: "Unknown language" for whoever doesn't know it at all. |
| **Spoken in the chat** | Offered next to the chat input. |
| **Deciphering** | A **roll** and a **difficulty**: clicking a scrambled passage rolls; on a success, it is readable for good for that character. **One attempt only** if you like. |

## Marking a passage

In a text editor (journal, description, note): select the passage, the toolbar's **Language** button, choose the language (or "None"). One text can mix several languages.

## What each person sees

- **The player** reads according to **their character** (the one assigned to their user; without a character, no language).
- **The GM** reads everything in clear. **View as** (at the top of the languages window) shows them texts and chat as a character reads them.
- **The chat**: the language button next to the input offers the spoken languages the character knows; everyone reads the message according to their mastery.

## Going further

Languages can be exported and imported. This is scrambling for the game, not encryption: a player digging through the console can read the original text.
